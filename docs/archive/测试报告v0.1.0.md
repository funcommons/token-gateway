## 一、被测对象

通用模型能力网关，双面形态：

- **LLM 同步面**：chat（同步/SSE 流式）、messages、models、count_tokens、embeddings、images 六端点；中继管线（凭证验证 → 渠道路由 → 计费 saga → 内容审核 → 上游转发）；横切（限流/幂等/审核/链路追踪/渠道健康上报）；THMP 契约面（HMAC + 影子比对 + 灰度切流，默认关闭）
- **任务面（face-task + task-worker）**：video/image/audio/tts 四模态 create/poll；lotask4j V4+ 平台托管（webhook 终态 + 资源代理 + 超时钟/对账 + notify 回调）；自写 Worker（lotask4j 拉单 + Groovy 三钩子沙箱 + fencing 回传）；计费 saga（全额预扣 → settle/refund 幂等闭环）

Maven 七模块：`gateway-spi`（SPI 冻结）/ `gateway-core` / `face-llm` / `face-task` / `task-worker` / `demo-control-plane` / `app`。

## 六、缺陷记录（出口演练实修，全部闭环）

冒烟打通过程暴露的缺陷按严重度归档（回归方式：单测用例固化 + 冒烟矩阵）：

| # | 级别 | 缺陷 | 根因 | 修复 |
|---|---|---|---|---|
| 1 | S1 | SUCCEEDED 终态 settle 从未接线，openHolds 永不归零（资资风险：预扣悬空） | TerminalEventHandler 只做退款分支 | `TaskBillingSaga.settleOnce` 幂等结算接入；冒烟第 7 步断言固化为出口门槛 |
| 2 | S1 | poll/终态资源透传上游原始 URL（安全：泄漏内网拓扑与渠道凭证位） | 遗留 TODO | `ResourceUrlConverter` 双路统一签名代理 URL，fail-closed；回源带渠道 key |
| 3 | S1 | Worker fencing 全被拒 → 任务被平台置 FAILED | 平台 CAS 成功即 version+1 且不回传，Worker 仍回传旧 version | `ClaimedTask.version` 本地同步递增 |
| 4 | S2 | webhook 400 重投耗尽 → 终态丢失 | 载荷字段为 `task_id` 非推测的 `id` | 双字段兼容 + verify-then-act 回查兜底 |
| 5 | S2 | 全部 lotask 写调用 401「未提供认证令牌」 | 平台 token 带会话指纹，自铸 JWT 一律被拒 | client_credentials 真登录 + 共享缓存 |
| 6 | S2 | 网关/Worker 互踢（「账号已在别处登录」）→ 登录风暴 | 平台单租户单会话互斥 | Redis 共享 token store + 登录单飞锁 + 401 只清被拒 token（防乒乓） |
| 7 | S2 | 「未知的 AccessKey」 | `X-Access-Key` 应为租户 **name** 非 id（平台 yml 注释有误） | DbSecretProvider 口径修正，文档/配置同步 |
| 8 | S3 | cancel 请求体与签名字节不同源 | `new byte[0]` vs `"{}"` | 同源修正 |

测试脚手架问题（非产品缺陷）一并修正：token-mock 全端点验 vendor key（预检/healthcheck 带 key）、demo reset 为 POST、产物 28B 最小 MP4 改 ftyp 魔数断言、冒烟端口避让（MMagiX 占 9400/9401）。

## 七、覆盖缺口与风险（如实声明）

1. **无覆盖率度量**：仓库未接 JaCoCo，263 用例的行/分支覆盖率无量化数据。建议 0.2.0 接入并设门槛（如行覆盖 ≥70%、face-task/core ≥80%）。
2. **任务面仅 video 模态走通全链路**：image/audio/tts 端点与数据面就绪，但无真实上游脚本，未过冒烟。CHANGELOG/Release Notes 已声明。
3. **降级矩阵负路径冒烟缺位**：超时钟 EXPIRED 退款、webhook 篡改拒绝、对账兜底、Worker 崩溃续租等仅单元层覆盖，未纳入 `smoke.sh`（正路径子集）。
4. **MMagiX 直连**：后端能力面 RPC 按 MMagiX 契约直连（M1 适配器化未完成），冒烟控制层为 demo 桩，不代表生产控制面契约。
5. **notify 验签冒烟断言条件生效**（见 §4），建议冒烟环境固定设钥。

## 八、结论

v0.1.0 满足出口标准：单元/切片 **263/263 全绿**、全链路冒烟 **18/18**（3 轮）、三流水线绿；出口演练暴露的 8 项产品缺陷全部修复并以单测+冒烟固化回归。已知限制（覆盖率未量化、非 video 模态无真实上游、降级矩阵负路径未冒烟化）已如实声明，作为 0.2.0 改进项。
