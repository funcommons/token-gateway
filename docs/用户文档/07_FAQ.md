# 常见问题（FAQ）

## 认证与凭证

**401 但凭证肉眼有效？**
命中后端侧凭证被禁用/租户停用——禁用即时生效。查后端凭证状态或联系平台。

**Bearer 和 x-api-key 都传了会怎样？**
Bearer 优先。建议只传一种，避免排障歧义。

## 调用与响应

**响应没有 `code` 字段，是失败吗？**
正常——成功响应是透传形状（无信封）。判定规则见[通用约定 §2](./03_通用约定.md)：有 `choices`/`content`/`task_no` 即成功，错误才带信封。

**10400 模型不存在？**
model 名不在任何已注册路由内。先 `GET /v1/models` 核对可用目录；目录为空 = 租户未开通任何模型。

**流式中途断开怎么办？**
网关按已产出估算结算（误差方向对调用方无成本损失），直接重试即可。建议客户端处理 `[DONE]` 缺失的断连分支。

**429 频繁触发？**
凭证维度窗口打满。读 `Retry-After` 指数退避；需要更高配额联系平台提额。

## 任务面

**create 返回了 task_no 但一直 PENDING？**
任务执行依赖 Worker + 对应上游的适配脚本。确认该模型所属上游的脚本已上线（平台方可查 Worker 日志 `script.*`）；长期 PENDING 会由超时钟判 EXPIRED 并全额退款。

**FAILED 后钱退了吗？**
退了。终态事件先退款（幂等）再 notify；若 webhook 丢失，超时钟/对账兜底任务会补退。重复退款由 `pre_consume_id` 幂等防住。

**代理 URL 过期了？**
代理 URL 有效期 24h（exp+sig）。重新 GET 任务详情可再签新 URL；任务结果本身长期可查。

**能跳过轮询只等回调吗？**
可以，但建议回调 + 轮询双保险：回调用于实时性，轮询用于回调丢失兜底（回调重发穷尽后仅告警）。

## 排障

**如何报障最有效？**
提供响应头的 `X-Trace-Id`（或信封里的 `trace_id`）+ 请求时间 + task_no（任务面）。一个 trace_id 贯通网关与后端日志。
