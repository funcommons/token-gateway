# 快速开始

5 分钟完成首次调用。开始前请确认：

- 已获得调用凭证（`sk-*` key，由平台方签发）
- 网关地址可达（默认 `http://localhost:9401`，生产地址以平台方通知为准）

## 第一步：验证凭证

```bash
curl -s http://<gateway-host>:9401/v1/models \
  -H "Authorization: Bearer <你的凭证>"
```

返回 `{"object":"list","data":[...]}` 即凭证有效；返回信封 `code=10202` 请核对凭证。

## 第二步：发起首次对话（LLM 面）

::: code-group

```python [OpenAI SDK（推荐）]
from openai import OpenAI

client = OpenAI(
    api_key="<你的凭证>",
    base_url="http://<gateway-host>:9401/v1",
)
resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
```

```bash [curl]
curl -s http://<gateway-host>:9401/v1/chat/completions \
  -H "Authorization: Bearer <你的凭证>" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"你好"}]}'
```

```python [Anthropic SDK]
import anthropic

client = anthropic.Anthropic(
    api_key="<你的凭证>",
    base_url="http://<gateway-host>:9401",   # SDK 自动拼 /v1/messages
)
msg = client.messages.create(
    model="claude-sonnet-4-5", max_tokens=1024,
    messages=[{"role": "user", "content": "你好"}],
)
print(msg.content[0].text)
```

:::

> 成功响应是**上游业务形状透传**（无信封），判定规则见[通用约定 §3](./03_通用约定.md)。

## 第三步：创建首个异步任务（任务面）

```bash
# ① 创建（同步返回 task_no；创建即全额预扣，余额不足 10617 且不产生任务）
curl -s http://<gateway-host>:9401/v1/videos \
  -H "Authorization: Bearer <你的凭证>" -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{"model":"vid-1.5","params":{"duration":5,"resolution":"720p"},
       "notify_url":"https://you/callback"}'
# → {"task_no":"T20260902...","status":"PENDING","poll_url":"/v1/videos/T20260902..."}

# ② 轮询（3~5s 驱动；终态幂等，重复轮询不触上游、不重复退款）
curl -s http://<gateway-host>:9401/v1/videos/T20260902... \
  -H "Authorization: Bearer <你的凭证>"
# → {"task_no":"...","status":"SUCCEEDED","result":{"resources":["<代理URL>"],"usage":{...}}}

# ③ 取资源（代理 URL 携带 24h exp+sig，免凭证直取）
curl -sL "http://<gateway-host>:9401<代理URL>" -o out.mp4
```

## 嵌入模式（starter）

不想独立部署网关 fat-jar？在自己的 **WebFlux** 应用里引用 starter，网关端点即装配进宿主进程（JitPack 发布，tag 即版本）：

```xml
<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>
</repositories>

<dependency>
    <groupId>com.github.funcommons.token-gateway</groupId>
    <artifactId>token-gateway-spring-boot-starter</artifactId>
    <version>v0.2.0</version>
</dependency>
```

配置同独立部署口径：

```yaml
token-gateway:
  face: llm        # llm | task | all（部署分组同款语义，非法值启动 fail-fast）
  enabled: true    # false 一键关闭（缺省开启）
  worker:
    enabled: false # true 把任务执行 Worker 也装进宿主进程（face=task|all 时生效）——
                   # 嵌入任务面的完整闭环无需另起 Worker 进程；缺省关闭
gateway:
  backend:
    url: http://localhost:9400
```

约束与限制：

- **宿主必须为 WebFlux 栈**（`spring-boot-starter-webflux`）：网关管线由 WebFilter 驱动，MVC（servlet）宿主下 starter 静默不装配
- 限流/幂等依赖 Redis：复用宿主的 `spring.data.redis.*` 连接配置即可
- `face=task` 需资源缓存盘挂载 + lotask4j 平台连通（见[任务面接入手册](./05_任务面接入手册.md)）；拉单执行开 `worker.enabled=true`（Worker 脚本目录、并发等沿用 `worker.*` 配置）
- 网关内部 bean 经组件扫描注册，不支持在宿主中以 `@Bean` 覆盖替换；需要定制请提 issue
- 运维端点（健康检查）需宿主带 `spring-boot-starter-actuator`
