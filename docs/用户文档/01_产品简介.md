# 产品简介

## 什么是 token-gateway

token-gateway 是**通用模型能力网关**：在调用方与多家模型服务之间提供统一入口——协议归一、凭证校验、路由定价、计费、审核、限流、幂等、日志审计一站收口。调用方用熟悉的 OpenAI / Anthropic SDK 改一行 `base_url` 即可接入；视频/图像/音频/TTS 等长耗时生成走异步任务面（创建→轮询→回调→资源代理）。

```
调用方 (OpenAI SDK / Anthropic SDK / curl / 业务后端)
        │  Authorization: Bearer <凭证>  或  x-api-key: <凭证>
        ▼
token-gateway (9401)  ── 协议归一 / 限流 / 幂等 / 审核 / 计费 saga / 日志 / 审计
        │  按能力面 yml 配置路由到后端服务
        ▼
后端服务：路由 · 凭证校验 · 计费 · 审核 · 日志(rpc/mq) · 审计 · 模型目录
任务面：lotask4j 平台托管任务状态 + 自写 Worker 执行上游（Groovy 脚本适配）
```

## 核心概念

| 概念 | 说明 |
|---|---|
| **面（face）** | 网关的两张数据面：**LLM 同步面**（对话/向量/生图，请求-响应即返）与**任务面**（四模态异步任务）。同 jar 异配置，可独立部署（`token-gateway.face=llm/task/all`） |
| **能力面** | 网关与后端之间的契约族：token-validate / route / billing / moderation / access-log / audit / model-catalog。每类一个地址，可分离部署也可同指单体 |
| **凭证** | 调用方身份即凭证（sk-* key），网关不签发凭证；凭证语义由命中的后端定义。**凭证不出现在任何日志与错误信息中** |
| **task_no** | 任务面任务号（`T+时间戳+随机`），创建即返；轮询/回调/资源代理均以其为键 |
| **错误信封** | 失败响应的 6 字段统一信封（`code/message/data/error/trace_id/timestamp`），`code` 为业务码（见[通用约定](./03_通用约定.md)） |
| **资源代理 URL** | 任务产物的访问地址：网关代理 URL 携带 `exp+sig` 24h 能力凭证，**上游原始 URL 永不透传** |

## 产品优势

- **协议归一**：OpenAI 形状进 OpenAI 形状出，Anthropic 同理；调用方不感知上游差异
- **计费准确**：先路由定价再预扣（模型不同价不同），按实际用量结算，失败自动退款
- **资金安全**：任务面全额预扣 + 终态幂等退款 + 预扣-终态对账兜底，无孤儿预扣
- **可观测**：全链路 `X-Trace-Id` 贯通网关↔后端↔访问日志
- **弹性部署**：LLM 面无 DB 无盘弹性扩缩；任务面挂资源缓存盘独立分组

## 适用场景

| 场景 | 说明 |
|---|---|
| 多模型统一入口 | 一套 OpenAI/Anthropic 协议访问多家上游，按模型路由定价 |
| 异步生成任务 | 视频/图像/音频/TTS 长任务：创建即返 task_no，轮询或回调取结果 |
| 多租户计费 | 凭证维度预扣/结算/退款，余额不足即拒（10617） |
| 合规审核 | 输入内容审核开关（可 fail-open），审计事件留痕 |
