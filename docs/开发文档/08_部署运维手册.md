# 08 · 部署运维手册

面向部署/运维人员：部署形态、配置参考、健康检查、验证与故障速查。配置以代码为唯一事实源：[`app/src/main/resources/application.yml`](../../app/src/main/resources/application.yml) 与 [`task-worker/src/main/resources/application.yml`](../../task-worker/src/main/resources/application.yml)。

## 1. 前置要求

| 项 | 要求 |
|---|---|
| JDK | 17+（Spring Boot 3.5） |
| Redis | 必需（限流/幂等/任务元数据），默认 `localhost:6379` |
| 后端控制层 | 必需（token-validate / route / billing / moderation 等能力面），默认 `http://localhost:9400` |
| lotask4j 平台 | `face=task/all` 必需；V4+，地址默认 `http://localhost:8080` |
| 资源缓存盘 | `face=task/all` 必需（资源代理缓存） |
| 端口 | 网关 `9401` / Worker `9411` / demo 控制层 `9400` |

## 2. 三种部署形态

### 2.1 独立部署（fat-jar，默认推荐）

```bash
mvn verify                       # 测试 + 覆盖率门禁
java -jar app/target/token-gateway-app-<version>.jar
```

`token-gateway.face` 部署分组（同一 jar，异配置）：

| face | 装载 | 依赖 |
|---|---|---|
| `llm` | 仅 LLM 同步面 | 后端控制层 + Redis；**无数据库无本地盘**，可水平扩缩 |
| `task` | 仅任务面 | + lotask4j 平台 + 资源缓存盘 + 快照/签名密钥 |
| `all` | 两面（默认，小规模） | 以上全部 |

face 值非法启动即 fail-fast。两面对 Redis/控制层的依赖同一套配置。

### 2.2 嵌入模式（starter）

WebFlux 宿主引用 `token-gateway-spring-boot-starter`（JitPack，tag 即版本），配置口径同上；MVC 宿主**静默不装配**（启动日志可见）。详见[快速开始「嵌入模式」](../用户文档/02_快速开始.md#嵌入模式starter)。

### 2.3 任务执行 Worker（face=task/all 的执行侧）

独立进程独立扩缩，与网关共用 lotask4j 租户凭证与快照密钥：

```bash
java -jar task-worker/target/token-gateway-task-worker-<version>.jar
```

关键项（`task-worker/src/main/resources/application.yml` `worker.*`）：

| 键 | 默认 | 说明 |
|---|---|---|
| `poll-interval` | 5s | 拉单节拍 |
| `pull-batch-size` | 4 | 单 tick 单 taskType 最大认领数（链式拉取） |
| `concurrency` | 8 | 单 Worker 并发任务数 |
| `scripts-dir` | `scripts` | Groovy 脚本目录 |
| `script-source` | `local` | `remote` = 控制层回调索取脚本（MMagiX 转接形态） |
| `egress-allowlist` | 空 | 出网 URL 前缀白名单，**空 = 全禁（fail-closed）** |
| `hook-timeout` / `max-task-duration` | 60s / 3h | 单钩子/单任务硬上限 |

## 3. 配置参考（网关侧）

> 所有密钥类配置一律环境变量注入，禁止入仓（`dev-` 前缀 = 本地无签名模式，仅限开发）。

### 3.1 控制层寻址与鉴权

| 配置 | 默认 | 说明 |
|---|---|---|
| `gateway.backend.url` | `http://localhost:9400` | 兼容回退目标（`token-gateway.*` 七面未配 url 的面回退到此） |
| `gateway.backend.internal-token` | 空 | 内部签名 JWT；`dev-` 前缀跳过签名；空 = 不发鉴权头（仅 localhost） |
| `token-gateway.route|token-validate|billing.{url,auth,jwt-secret}` | 回退 backend.* | 每类控制面服务独立寻址/鉴权/超时，可分离部署 |
| `token-gateway.adapter` | `mmagix` | 协议形状适配器全局单选（mmagix/tokenhub/tokengo/openapi/custom:\<spiName\>） |

### 3.2 任务面（face=task/all）

| 配置 | 默认 | 说明 |
|---|---|---|
| `token-gateway.task.lotask.url` | `http://localhost:8080` | lotask4j 平台地址 |
| `token-gateway.task.lotask.tenant-secret(-previous)` | 必配 | webhook 验签密钥；`-previous` 双值窗轮转（grace 期双钥） |
| `token-gateway.task.lotask.webhook-callback-url` | 必配 | 平台回调网关的地址 |
| `token-gateway.task.snapshot-cipher-key` | 必配 | 路由快照加密（Base64 32B；Worker 侧同钥） |
| `token-gateway.task.resource-sign-key` | 必配 | 资源代理 URL exp+sig 签名 |
| `token-gateway.task.submit-task-type` | `modality` | `model` = 远程 Worker 按 modelCode 认领（切换后 timeouts 键同步） |
| `token-gateway.task.lotask.max-submit-size` | 64MB | submit 出站载荷上限（base64 参考图等大载荷；超限 413/10100，env `TGW_LOTASK_MAX_SUBMIT_SIZE`） |
| `token-gateway.task.timeouts.{video,image,...}` | video 2h / image 30m | 模态超时钟 |

### 3.3 横切行为

| 配置 | 默认 | 说明 |
|---|---|---|
| `spring.codec.max-in-memory-size` | 128MB | 请求体上限（base64 图等大载荷；env `GATEWAY_MAX_BODY_SIZE`） |
| `gateway.failover.{enabled,max-attempts,base-backoff-ms}` | true / 3 / 1000 | 请求内渠道轮换；false 退化为单渠道快速失败 |
| `gateway.health-report.enabled` | true | 渠道健康上报（record-success/failure） |
| `gateway.thmp.*` | false | TokenHub 契约面影子比对/灰度切流，默认关闭 |
| `token-gateway.task.lotask` 审核相关 | — | 审核面 `fail-open` 缺省 true（故障放行）；合规优先可配 false 拦截 |

## 4. 健康检查与验证

```bash
curl -s http://localhost:9401/actuator/health          # 网关（actuator 暴露 health,info）
curl -s http://localhost:9401/v1/models -H "Authorization: Bearer <key>"   # 链路通断（经控制层）
```

全链路冒烟（五进程零真实依赖）：`docker compose -f docker-compose.smoke.yml up -d` + 按[租户开通手册 §5](./07_lotask4j租户开通手册.md) 拉起后 `bash scripts/smoke.sh`（PASS/FAIL 矩阵，非零退出码 = 有 FAIL）。

## 5. 故障速查

| 现象 | 排查 |
|---|---|
| 启动 fail-fast「task.lotask.url 未配置」 | `face=task/all` 必配 lotask 地址 |
| 调用返回 `504/10003` | 凭证校验服务瞬时不可用（网关→控制层链路抖动），可重试；持续出现查 `gateway.backend.url` 可达性与控制层日志 |
| 调用返回 `401/10202` | 凭证真失效（禁用/租户停用即时生效），查控制层凭证状态 |
| create 502/10004 | lotask submit 失败：平台侧鉴权（401=token 无效查 `client_id`；签名拒绝=ACCESS_KEY/SECRET 错位） |
| 任务一直 PENDING | Worker 未起/脚本缺失（Worker 日志 `ScriptLoader`）；平台 `asts_task` 状态与 Worker 心跳 |
| webhook 收不到 | 平台→网关网络；平台 outbox 投递状态；`LOTASK_WEBHOOK_CALLBACK_URL` 可达性 |
| notify 未收到 | 网关日志 `[Notify]`；调用方地址可达性；退避档位耐心等 |
| 对账 openHolds 非空 | `[Reconcile]`/`[TimeoutClock]` 日志；平台终态与 webhook 是否到达 |
| 资源代理 404/过期 | 代理 URL 24h 过期（exp+sig），重取任务可再签；篡改 → 10100 |

## 6. 日志与排障

- 日志键：`logging.level.fun.commons.tokengateway=DEBUG`（默认已开）；请求链路 `trace_id` 贯通网关↔控制层↔访问日志（响应头 `X-Trace-Id`）。
- 凭证不出现在任何网关日志与错误信息中。
